# Debug

Start from observable evidence: reproduce the issue, capture the exact failure, and trace the smallest affected path. Form hypotheses from code and logs, then test each with focused instrumentation or checks. Identify the root cause rather than patching the symptom. Make the smallest safe fix, add a regression test when practical, and report reproduction, cause, change, and validation. Preserve unrelated behavior and clearly state any environment blocker.
